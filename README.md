# NEON KART RUSH

Mario-Kart-style browser racer: drift, items, AI rivals, minimap, 3 laps.

## Play

https://michaelpaa.github.io/aether-pulse/

## Controls

- **A/D or ←/→** steer
- **W/↑** accelerate
- **S/↓** brake / reverse
- **Space** drift (release for mini-boost)
- **Shift** use item

## Items

Boost, shell, banana, lightning — worse place gets better RNG.
