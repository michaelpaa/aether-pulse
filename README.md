## Cluck GP

Default field is funny cartoon chickens (Chickensoft mascot, CC BY 4.0) on Kenney CC0 karts. Optional **18+** (start overlay or HUD, confirm once, not saved) swaps in stylized adult female racers. Never childlike, never photoreal photos of real people.

Controls: WASD/arrows drive, Space shoot, Q cycle weapons (egg / homing corn / feather), Shift/E boost. 3 laps, 4 racers, item boxes, boost pads, jump, fall-reset.
